# cyclistic_bike_share_analysis
case study for the cyclistic bike company to create an insights about potential data-driven improvements for the subscription system of the company.
Project Overview: Cyclistic Bike-Share Case Study : This portfolio project analyzes historical trip data for Cyclistic, a fictional bike-share company in Chicago, to solve a core business objective assigned by Director of Marketing Lily Moreno: "How do annual members and casual riders use Cyclistic bikes differently?"   By uncovering behavioral divides between annual subscribers (who use bikes primarily for daily commuting and utility) and casual riders (who use them for seasonal recreation and extended leisure), the analysis informs targeted conversion strategies designed to turn casual riders into annual members without risking existing subscription revenue.   Project Components & File GuidelinesYour completed GitHub repository and project portfolio are structured into the following modular components:sql/ (SQL Pipeline Scripts)01_data_combination.sql – Stacks and merges 12 consecutive months of raw trip data via UNION ALL into a single unified master table.02_data_cleaning.sql – Filters out invalid data outliers (such as trips under 1 minute or over 24 hours), formats timestamps, and calculates exact trip durations in minutes (trip_duration_minutes).03_exploratory_analysis.sql – Aggregates metrics by rider type, seasonality, and time of day to extract actionable insights.the_data/ (Data Directory & Spreadsheets)Houses documentation files and a text reference linking directly to your external processed Google Sheets summary tables.Note: Raw multi-million-row CSV files are processed directly in Google BigQuery rather than stored locally in GitHub, following data analytics best practices.Presentation Deck (Stakeholder Deliverable)A polished, executive-ready slide deck (exported as a PDF or hosted via Canva) designed for non-technical stakeholders.Highlights the executive summary, overarching metrics (total trips vs. average duration), seasonal trends, time-of-day commute curves, and top strategic recommendations (such as offering a targeted commuter pass exclusively to non-members and a seasonal "Long-Ride Pass").
